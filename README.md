### 🎫 [Ticket Triage Service](https://github.com/manvithh06/ticket-triage-service)

### 🔎 [Research Agent](https://github.com/manvithh06/research_agent)
**Autonomous research agent built from first principles: no LangChain, no abstractions.**
 
- Hand-rolled **ReAct loop** (Reason → Act → Observe) with a pre-loop **planner**
- Tools: Wikipedia, DuckDuckGo web search, and an **AST-sandboxed calculator** (no raw `eval`)
- Long-term **vector memory**: past Q&A embedded with MiniLM and recalled through **FAISS** cosine search
- **5 independent safety layers**: iteration cap, time limit, failure streaks, empty-output and answer validation
- FastAPI backend that **streams each reasoning step live** over Server-Sent Events

### 🌀 [CIRCULO](https://github.com/manvithh06/circulo-agentic)
**Agentic industrial-symbiosis engine: four autonomous agents find who can reuse a factory's waste.**
